## Static Website Prototype

This repository now includes a simple static prototype of the coaching portal.

### Viewing the Site

1. Open the `site/index.html` file in your web browser.
2. Use the navigation links to access the login page, student dashboard, and admin dashboard.
3. On the home page you can use the **Set Background** button to upload a background image and the **Add Photo** button to build a small gallery.

These pages are placeholders that demonstrate the basic structure of the planned application.
